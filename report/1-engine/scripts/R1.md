# Confirmatory input contract

`data/r1/samples.csv` stores every confirmatory sample in long form. Its columns
are `run`, `dataset`, `problem_id`, `sample_idx`, `is_correct`,
`pass_stat_tokens`, `mean_passes_per_token` and
`fraction_tokens_at_least_2_passes`. Rows are sorted by declared run order,
dataset, problem ID and sample index. No generation text or unused CSV fields
are retained.

`data/r1/runs.json` combines the run declarations, completion statuses, group
settings, engine telemetry, expected problem IDs, source inventory and
deviations. For each run it records the source directory, all relevant source
paths and hashes, config values and the protocol-manifest SHA256 when one
exists. The direct seed-2024 run has no protocol manifest, so its hash is null.
`data/MANIFEST.json` also records source paths and source hashes for both
compact files.

The analyzer checks the frozen reference seed and engine seeds, complete sample
coverage, duplicate keys, run statuses and every group setting against the
registered workload. It adapts the compact rows into temporary files under
`data/tmp/report-1-engine/checks/` for the existing CPU API in
`script/tah/evaluation/compare_runs.py`; the repository comparator is not
changed. The analyzer uses `_run_group` and `_pair_analysis` for paired
Student-t intervals and TOST.

Run confirmatory generation with the committed protocol presets and runner,
following `report/PROTOCOL.md` and `guide/evaluation.md`. The final archive is
curated by `scripts/curate_r1.py` from the experiment directories. It hashes
the sorted-key JSON inventory of `tah/engine/*.py` at the frozen commit via
`git show`, and retains full generations and raw telemetry at the recorded
source paths.

Missing `runs.json`, `complete: false`, or incomplete statuses produce a
pending section. Hash mismatches, duplicate pairs, wrong seeds, inconsistent
engine hashes, settings differences or incomplete problem/repeat coverage
fail loudly. On completion, `tables/r1.tex` and `tables/r1-analysis.json`
contain pooled and per-dataset engine/reference comparisons, pass ratios, TOST
and declared deviations. Analysis never reruns generation.
